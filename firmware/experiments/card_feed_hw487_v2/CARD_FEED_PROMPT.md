```text
你正在维护 `C:\Users\32126\Desktop\Robitics\firmware\card_feed_hw487_v2\card_feed_hw487_v2.ino`。
只修改这个子文件夹，绝不覆盖 `firmware\single_motor_m2_test` 或 `firmware\motor_bridge` 中的原文件。

目标：为 Arduino Mega + AFMotor V1/L293D 的单电机送牌机构做稳定的 HW-487 闭环送牌。

当前硬件：
- 送牌电机接 Motor Shield M2。
- HW-487 槽型光电传感器：S -> Mega D22，+ -> 5V，GND -> GND。
- 可选舵机：信号线 D23，独立 5V 供电，必须与 Mega 共地。
- APDS-9960 如仍连接：SDA -> D20，SCL -> D21；它不是本版本送牌检测的主传感器。

期望控制语义：
1. 电机只低速、小步送牌，不允许持续高速把多张牌一起拉出。
2. HW-487 遮光表示牌进入检测槽；光束恢复表示牌尾已完全离开检测槽。
3. 只有“遮光 -> 恢复光束”才计为一张牌完全通过。
4. 停机后的惯性可能带出下一张牌：若它也完整通过，应单独计数，并从它离开的时刻重新等待 1 秒。
5. 牌仍在检测槽时，不得启动下一次送牌。
6. 任意时刻串口 `0` 或 `STOP` 必须立即停止电机；`1` 启动自动送牌。

当前已知问题：
- 送牌机构可能一次带出多张牌，因此优先确保单张、可解释的检测，再逐步调参。
- 单个 HW-487 无法区分多张牌紧贴且始终遮光的情况；不要把连续遮光误报成多张。
- PWM 不是线性速度：过低会停转，过高会带出多张。当前主送牌速度约 180，检测槽通过速度约 150，必须基于实测调整。

工作方式：
- 先阅读现有状态机、串口命令和顶部可调参数。
- 每次修改后说明状态转换和可调参数。
- 保留电机反转保护、串口急停和无命令超时停车。
- 未经明确要求，不删除现有 APDS、舵机或手动控制命令；可以将无关功能禁用但要说明原因。
- 给出 Arduino IDE 可直接上传的代码；如本机没有 arduino-cli，明确说明未进行实际编译/硬件验证。
```
