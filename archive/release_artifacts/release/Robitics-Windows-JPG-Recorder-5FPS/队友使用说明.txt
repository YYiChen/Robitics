Robitics 本地 JPG 记录器（默认 5 FPS）
========================================

用途
----
从树莓派的视频地址读取 MJPEG 视频流，将图片直接保存到本机电脑。
图片不会保存到树莓派。

使用前
------
1. Windows 电脑需安装 Python 3（安装时勾选 Add Python to PATH）。
2. 确保浏览器可以打开：http://树莓派IP:5000/video_feed

使用方法
--------
1. 双击“启动本地JPG记录器.bat”。
2. 在“树莓派视频流地址”填写实际地址，例如：
   http://100.80.46.54:5000/video_feed
3. 点击醒目的“选择保存位置…”按钮，选择要保存 JPG 的文件夹。
4. 点击“开始保存（5 FPS）”。
5. 点击“停止保存”结束。

说明
----
- 默认每秒保存 5 张 JPG。
- 网络断开时自动每 3 秒重试。
- 剩余磁盘空间低于 5 GB 时自动停止，避免写满磁盘。
