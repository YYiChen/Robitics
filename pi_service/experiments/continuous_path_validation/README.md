# 连续路径前视循迹（独立验证）

适用于连续的黑色或白色胶带路径，不假设矩形、八边形、固定转弯次数或固定转向方向。可用于六边形、七边形、八边形和由多段直线组成的连续折线路线。

每帧从紫色骨架路线取得 `LOOKAHEAD` 前视点，再用差速 P 控制向该点连续转向。默认安全行为：启动看不到线即停车；已开始循迹后，先按最后一次路径曲率预测 0.75 秒，再最多滑行至 1.00 秒；仍未重新看到线才停车。停车后若再次看到线会自动恢复循迹，避免车辆惯性带回胶带时永久停住。先以显示模式验证，再添加 `--enable-motors` 实车低速测试。

短暂丢线期间会保持最后一次有效的左右轮 PWM（包括转弯差速），而不是退化成直行；这用于通过胶带接缝、运动模糊和斜角的短视觉空档。

浏览器预览端口为 `5054`。
