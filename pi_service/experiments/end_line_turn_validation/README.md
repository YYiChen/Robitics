# 单白线红终点带验证

当前场地只使用一条纵向白胶带，以及两端各一条独立的红色横向终点带。

当前网页控制分成两个互不混用的入口：

- `M` 只解锁原有半自动排障模式，再用 `Q/E/U/I` 触发左/右 90°、180° 转向；只按 `M` 不会自动前进。
- `N` 启动一次完整任务：沿白线行驶到另一端，确认红色终点与白线消失后停车，原地左转 90°，然后关闭电机门控。

自动任务运行中再次按 `N`，或者按 `M`，都会立即取消任务并停车。没有近期红色终点证据的丢线只会触发安全停车，不会开始转向。

红带从白线掩膜中隔离：白线控制使用 HSV 低饱和亮色；终点带使用 `R - max(G,B)`。
